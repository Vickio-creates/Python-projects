# Python Projects
A collection of Python programs built while learning Python fundamentals.

## Temperature Converter
A CLI tool that converts Celsius to Fahrenheit and Kelvin,
and classifies the temperature as Freezing, Cold, Warm or Hot.

### How to run
```bash
python temperature_converter.py
```

### Concepts used
- float() type conversion
- f-strings for formatted output
- while loop with break
- if/elif/else conditions
- input() function
