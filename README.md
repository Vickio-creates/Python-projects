# Python Projects
A collection of Python programs built while learning Python fundamentals.

## 1. Temperature Converter
A CLI tool that converts Celsius to Fahrenheit and Kelvin,
and classifies the temperature as Freezing, Cold, Warm or Hot.

### How to run
```bash
python temperature_converter.py
```

### Concepts used
- float() type conversion
- f-strings for formatted output
- while loop with break
- if/elif/else conditions
- input() function

## 2. Study Progress Tracker
A CLI tool that tracks subject scores, calculates the average
and rates overall performance as Excellent, Pass or Fail.

### How to run
```bash
python study_tracker.py
```

### Concepts used
- Lists and dictionaries
- while loop with break
- for loop to iterate results
- Average calculation
- f-strings for formatted output
- input() function
